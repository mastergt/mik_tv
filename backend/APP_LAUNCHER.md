# mik_tv v0.3.2 — приложения в Android-лаунчере

Главный экран Android (телефон, планшет, приставка) показывает **типы приложений из admin UI**, а не список TV-каналов.

## Backend
Новый авторизованный endpoint:
```http
GET /api/v1/client/app-types
Authorization: Bearer <client_token>
```
Ответ — массив:
```json
[
 {"id":1,"code":"tv","name":"ТВ","icon":"📺","sort_order":100,"stream_count":2},
 {"id":2,"code":"cctv","name":"Видеонаблюдение","icon":"📹","sort_order":200,"stream_count":0}
]
```
Возвращаются только **включённые** типы `catalog.app_types`. `stream_count` вычисляется на основе
тех же ограничений, что и `/client/streams`: provider visibility, гостевой/авторизованный доступ,
назначенные плейлисты, parental controls. Типы без потоков тоже отображаются, поскольку
они настраиваются администратором; это не предоставляет доступ к закрытым потокам.

Сортировка: тип `tv` всегда первый, остальные — по `sort_order`, затем ID.
Поле `icon` — опциональная короткая строка (обычно emoji); Android по умолчанию
использует иконку по коду типа.

## Админка
«Типы приложений» -> редактирование: название, код, активен/выключен,
**порядок отображения**, **иконка**. Редактирование требует глобального `streams.write`.

## Развёртывание
Никаких новых переменных `.env` для v0.3.2 нет. Существующие домены сохраняются:
API `https://miktv.artelmik.ru/api/v1`, админка `https://admin.miktv.artelmik.ru`.

После обновления проекта:
```sh
cd /usr/local/nodejs/dev/iptv_front/backend
# Получить DATABASE_URL из текущего .env, не публиковать пароль
set -a
. ./.env
set +a
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 \
  -f database/migrations/0011_app_launcher.sql

npm ci
npm run check
npm run build
npm test
# Перезапустить уже настроенный PM2-процесс NestJS (имя сверить по pm2 list)

cd ../frontend
npm ci
npm run check
npm run build
```
Затем перечитать Nginx только если ранее менялись его конфиги; для этой версии новых vhost не нужно.
Применить `0011` **до перезапуска нового backend**: он читает `sort_order` и `icon`.

Проверка после авторизации:
```sh
curl -H "Authorization: Bearer <client_token>" \
  https://miktv.artelmik.ru/api/v1/client/app-types
```

## Android
- `autostart_app=tv` по умолчанию (локально на терминале).
- Настройка из главного экрана: «Автозапуск: ...» -> выключен или мини-приложение.
- ТВ открывает последнее/первое доступное вещание, сохраняет предыдущее меню EPG,
  а выход из плеера возвращает на главный экран, не вызывая автозапуск снова.
- CCTV/Intercom/Radio пока только плитки с пометкой «В разработке».
- Старое устройство с сохранёнными настройками TV-провайдера и токеном должно
  продолжать работать; debug-подпись может потребовать переустановку приложения.
