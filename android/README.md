# mik_tv · первое Android-приложение (v0.1.0)

Это **нативный Android-клиент** из проекта [mastergt/mik_tv](https://github.com/mastergt/mik_tv). Один APK для Android TV, Google TV, обычных AOSP-приставок, телефонов и планшетов. Общие API и Media3 ExoPlayer; два режима интерфейса (список с боковой панелью на TV, вертикальный список на мобильных устройствах). Можно выбрать TV/Mobile вручную, если приставка не объявляет Leanback.

## Что работает в MVP

- Настройка адреса **HTTP(S) сервера** и выбор провайдера из `GET /api/v1/client/bootstrap`.
- Регистрация терминала `POST /client/register`, устройство получает постоянный UUID и секрет. Токен и секрет шифруются в локальном Android Keystore (AES-GCM, Android 6+).
- Вход/выход абонента через `/client/auth/login` и `/client/auth/logout`, проверка `/client/me` при запуске. Гостевые каналы доступны без входа, если их разрешил backend.
- Каталог `/client/streams`: догрузка страниц по 200, поиск по названию/номеру/жанру, фильтр жанра, избранное.
- Получение EPG, запрос DVR для выбранной прошлой/текущей передачи по существующему API.
- Media3/ExoPlayer для HTTP(S) HLS и MPEG-TS, а также RTSP. UDP multicast пока не воспроизводится. Сначала пробует резервные источники. Повторные подключения к LIVE ограничены.
- Полноэкранный проигрыватель с D-pad CH+/CH- и стандартными медиаклавишами. Удержание строки каталога добавляет/удаляет избранное.

**Не реализовано в v0.1.0:** фоновые push-уведомления (потребуют выбора FCM/собственного механизма), дизайн Compose, PiP, Android Auto, офлайн-каталог, M3U/UDP direct, адаптивный полноэкранный гид EPG, родительский контроль и публикация в Google Play.

## Сборка APK

Рекомендуемый путь — GitHub Actions в корне репозитория, workflow **Android APK (mik_tv)**. Он запускает `gradle :app:testDebugUnitTest :app:assembleDebug`, публикует артефакт `mik_tv-debug-apk`. Скачайте его через вкладку **Actions** → успешный запуск → **Artifacts**.

Локально с Android SDK API 36 и JDK 17:

```bash
cd android
gradle :app:testDebugUnitTest :app:assembleDebug --no-daemon
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Android Studio: открыть каталог `android/`, дождаться Gradle Sync, затем Build → Build APK(s).

**Внимание:** это тестовый APK (debug), подписанный стандартным debug-ключом CI. Не используйте его для публикации в магазине, пока не настроен свой постоянный release signing key. Не храните приватные signing-ключи в репозитории.

## Подключение

1. Установите APK на телефон/Android TV/AOSP-приставку (при необходимости разрешите установку из неизвестных источников).
2. Запустите **mik_tv**.
3. Введите адрес базового API. Если API опубликован на `https://tv.example.ru/api/v1`, можно указать и просто `https://tv.example.ru`.
4. Нажмите «Проверить сервер», выберите провайдера и режим интерфейса.
5. Подключитесь. Для платных телеканалов используйте «Вход» с учётной записью абонента.
6. Выберите канал → OK; кнопка EPG открывает телепрограмму. Долгое нажатие на строку добавляет её в избранное.
7. В видеоплеере CH+/CH− переключают каналы; BACK возвращает в каталог.

При смене провайдера создаётся отдельный UUID устройства. Один терминал нельзя молча привязать к другому провайдеру (ограничение backend).

## Безопасность и совместимость

- В `AndroidManifest.xml` разрешён **HTTP**, чтобы тестировать существующий портал и AOSP-приставки. Для реальной авторизации абонентов рекомендуется HTTPS: при HTTP пароль, регистрационный секрет и токен могут быть перехвачены по сети.
- Локальные токены и `device_secret` не сохраняются в открытом виде; если Android Keystore не работает на конкретной прошивке, регистрация честно сообщит об ошибке. На некоторых бюджетных приставках может понадобиться отдельная реализация хранилища.
- Формат API сверялся по **реальным исходникам backend**: никаких новых таблиц, миграций и маршрутов не требуется.
- Параметр minSdk=23 (Android 6.0), compileSdk=36, Kotlin 2.2.20, AGP 8.11.1, Media3 1.11.1.
- Аппаратное воспроизведение, клавиши пульта, HTTPS-доверие и Keystore пока **не подтверждены на настоящих устройствах**.
- Код требует компиляции Android SDK/Gradle. В среде создания проекта Android SDK недоступен; без успешного CI нельзя утверждать, что APK уже готов к установке.
