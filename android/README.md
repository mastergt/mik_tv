# mik_tv Android v0.3.0 — автоматическое обнаружение backend и провайдера

По умолчанию приложение (Android TV, AOSP-приставки, телефоны и планшеты) при запуске делает:
`GET https://start.iptv.artelmik.ru/api/v1/client/discover`.
Сервер определяет провайдера **по внешнему IP клиента** (CIDR и провайдер по умолчанию)
и возвращает `api_base_url`, `provider.slug`, `provider.name`, `match`.

Приложение автоматически сохраняет полученный HTTPS endpoint и slug и регистрирует
или восстанавливает сессию терминала как прежде. Никаких других доменов по умолчанию
не используется. При 404 отображается «Провайдер не найден для вашего IP-адреса»;
есть кнопки повторного поиска и ручной настройки. Ручной режим сохраняется для
диагностики и отключается через переключатель «Автоопределение провайдера по IP».

**Важно для теста на POCO M6 Pro:** DNS и сертификат `start.iptv.artelmik.ru`
должны работать, backend-миграция выполнена и провайдеру назначена сеть телефона
или активный провайдер по умолчанию. Иначе вход по IP намеренно не сработает.
При смене выявленного провайдера может потребоваться новая регистрация терминала.

`versionCode=7`, `versionName=0.3.0`; одна кодовая база TV/Mobile.
Сборка APK запускается через GitHub Actions (`mik_tv-debug-apk`).
Для обновлений без удаления debug-версии нужен постоянный ключ подписи,
как и раньше. Подробный deployment guide: `backend/PROVIDER_DISCOVERY.md`.

# mik_tv Android v0.2.4 — компактная текущая передача в EPG

Минимальная доработка интерфейса по результатам теста на POCO M6 Pro:

- Удалена дублирующая верхняя строка **«Сейчас: ... · Далее: ...»**. Выше списка остаётся только название выделенного телеканала.
- В правом списке EPG текущая передача отмечается значком **▶** и жёлтым цветом. Название и время передачи выводятся в одной строке.
- Сразу под текущей передачей остаётся тонкая **двухцветная полоска прошедшего/оставшегося времени**, добавленная в v0.2.3. Без текстовых подписей.
- Следующие и прошлые передачи остаются обычного белого цвета. Перерасчёт прогресса каждые 15 секунд сохранён.
- HLS-воспроизведение не прерывается при открытии меню, работа ExoPlayer и API не менялась.
- Android `versionCode=6`, `versionName=0.2.4`; backend, PostgreSQL и портал не затронуты.

Сборка через GitHub Actions: `gradle :app:testDebugUnitTest :app:assembleDebug`, результат `mik_tv-debug-apk`.

# mik_tv Android v0.2.3 — индикатор прохождения текущей передачи

Небольшая точечная доработка TV-меню v0.2.2 по скриншоту старого приложения:

- В правой колонке EPG **строго под текущей передачей** — горизонтальная двухцветная полоска шириной 112 dp и высотой 4 dp.
- **Светлая часть** соответствует времени, уже прошедшему от начала передачи; **тёмно-серая часть** — оставшемуся времени до окончания.
- Например, если передача длится 60 минут и идёт 15 минут, bar = 25% светлой части и 75% тёмной.
- В прошедших передачах, будущих передачах и разделителях по дням полоски нет.
- Пока меню открыто, прогресс обновляется раз в **15 секунд** по времени устройства и времени начала/окончания из EPG. Никаких дополнительных API-запросов и никакого влияния на работающий ExoPlayer.
- Для неверных интервалов длительности вычисление безопасно возвращает 0%; границы прогресса ограничены диапазоном 0–100%.
- Версия v0.2.3, versionCode=5. Только Android-клиент. Видео по-прежнему воспроизводится под меню, параметры буферизации не изменены.

После merge и успешного GitHub Actions скачай артефакт `mik_tv-debug-apk`. Проверка: `cd android && gradle :app:testDebugUnitTest :app:assembleDebug --no-daemon`. Существующая debug-подпись может отличаться — см. ниже особенности установки.

# mik_tv Android v0.2.2 — меню телеканалов поверх LIVE

Обновление для POCO M6 Pro и Android TV по образцу старого телевизионного меню.

## Как работает

- **Одно касание по видео** открывает затемнённый полупрозрачный экран: сверху жанры, слева каналы, справа программа передач выбранного канала. Существующий ExoPlayer продолжает проигрывать LIVE без переподключения.
- Категория **«Все»** открыта по умолчанию. Затем «Избранное» и жанры из API. Категории и каналы берутся из уже загруженного каталога, без массовой фоновой загрузки.
- Текущий канал отмечен ▶, выбранный выделен золотистым. **Одно касание канала** — только выбор и показ EPG. **Второе касание** (в пределах 1,6 сек) либо **OK пульта** — подтверждает переключение.
- EPG запрашивается только для выделенного канала (задержка 230 мс), кэш 60 секунд, разделители по датам, текущая и следующая передачи. При выборе записи можно открыть описание и доступный DVR.
- Верхний левый значок ↖ пока возвращает на предыдущий экран каталога; отдельное главное меню — следующий этап.
- Кнопка ✕ или BACK закрывают наложение. Свайпы по видео вне меню продолжают переключать канал, громкость и яркость. Пока меню открыто, свайпы перемещают списки.
- Кнопки паузы, перемотки, шкала прогресса и верхняя плашка Media3 остались отключёнными, как в v0.2.1.
- Экран меню существует как View в той же PlayerActivity, **не отдельная Activity**; просмотр каналов и EPG не вызывает `player.stop()`, `setMediaItem()` или `playback/start`.

## Как получить APK

После merge PR запускается GitHub Actions. Для тестирования можно скачать Artifact **mik_tv-debug-apk** из workflow ветки. В архиве `app-debug.apk`.

Ветку проверяет:
```bash
cd android
gradle :app:testDebugUnitTest :app:assembleDebug --no-daemon
```

VersionCode 4, VersionName 0.2.2. Нужна проверка на физическом POCO M6 Pro: переключение выбранного канала, правильность категорий и EPG, отсутствие остановки LIVE во время открытого меню.

**Важно:** разные debug-подписи CI могут потребовать переустановки; удаление приложения удалит локальную регистрацию терминала. Для обновлений без переустановки используйте release APK с постоянным ключом. Требования к HTTPS при авторизации не меняются. Backend, БД и портал не изменяются.
