# mik_tv Android v0.2.2 — меню телеканалов поверх LIVE

Обновление для POCO M6 Pro и Android TV по образцу старого телевизионного меню.

## Как работает

- **Одно касание по видео** открывает затемнённый полупрозрачный экран: сверху жанры, слева каналы, справа программа передач выбранного канала. Существующий ExoPlayer продолжает проигрывать LIVE без переподключения.
- Категория **«Все»** открыта по умолчанию. Затем «Избранное» и жанры из API. Категории и каналы берутся из уже загруженного каталога, без массовой фоновой загрузки.
- Текущий канал отмечен ▶, выбранный выделен золотистым. **Одно касание канала** — только выбор и показ EPG. **Второе касание** (в пределах 1,6 сек) либо **OK пульта** — подтверждает переключение.
- EPG запрашивается только для выделенного канала (задержка 230 мс), кэш 60 секунд, разделители по датам, текущая и следующая передачи. При выборе записи можно открыть описание и доступный DVR.
- Верхний левый значок ↖ пока возвращает на предыдущий экран каталога; отдельное главное меню — следующий этап.
- Кнопка ✕ или BACK закрывают наложение. Свайпы по видео вне меню продолжают переключать канал, громкость и яркость. Пока меню открыто, свайпы перемещают списки.
- Кнопки паузы, перемотки, шкала прогресса и верхняя плашка Media3 остались отключёнными, как в v0.2.1.
- Экран меню существует как View в той же PlayerActivity, **не отдельная Activity**; просмотр каналов и EPG не вызывает `player.stop()`, `setMediaItem()` или `playback/start`.

## Как получить APK

После merge PR запускается GitHub Actions. Для тестирования можно скачать Artifact **mik_tv-debug-apk** из workflow ветки. В архиве `app-debug.apk`.

Ветку проверяет:
```bash
cd android
gradle :app:testDebugUnitTest :app:assembleDebug --no-daemon
```

VersionCode 4, VersionName 0.2.2. Нужна проверка на физическом POCO M6 Pro: переключение выбранного канала, правильность категорий и EPG, отсутствие остановки LIVE во время открытого меню.

**Важно:** разные debug-подписи CI могут потребовать переустановки; удаление приложения удалит локальную регистрацию терминала. Для обновлений без переустановки используйте release APK с постоянным ключом. Требования к HTTPS при авторизации не меняются. Backend, БД и портал не изменяются.
