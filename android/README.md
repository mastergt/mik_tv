# mik_tv Android v0.2.0

Первый пользовательский выпуск после проверки **v0.1.0 на POCO M6 Pro**. Один проект и APK для телефона, планшета, Android TV и AOSP-приставок; интерфейс автоматически определяется по Android UI mode / Leanback, его можно переопределить вручную.

## Что улучшено

- Новый каталог с **логотипами каналов**, номером, названием, жанрами и отметкой избранного; строка переиспользуется через `ListView`, изображения скачиваются в двух фоновых потоках с ограничением по размеру и кэшем 3 MiB.
- На телефоне — прокручиваемые **чипы категорий**, на TV — выбор категории с пульта, крупные строки и фокус.
- Блок **«Сейчас / Далее»** для выбранного канала. EPG не запрашивается одновременно для каждого канала; запоздавшие ответы отфильтровываются по номеру запроса.
- Список EPG с выделением текущей передачи, подробным описанием и возможностью запустить архив; для незаписанных и будущих передач кнопка архива не показывается.
- В нативном плеере — название канала, текущая и следующая передачи, EPG, LIVE и ручной повтор. Информационная панель скрывается после начала просмотра и появляется по касанию/OK.
- На телефоне: **свайп влево/вправо** переключает канал; **вертикальный свайп слева** меняет яркость экрана, справа — громкость. Видео открывается в альбомной ориентации.
- Последний воспроизведённый канал сохраняется для текущих сервера/провайдера; восстанавливается выделение в каталоге, без автоматического запуска видео.
- Media3/ExoPlayer, оригинальная авторизация/регистрация и playback lease сохранены.
- Версия APK: `versionCode=2`, `versionName=0.2.0`; Android 6+.

## Как получить APK

Открой GitHub → Actions → **Android APK (mik_tv)** → успешный запуск ветки/PR → Artifacts → `mik_tv-debug-apk`. Внутри находится `app-debug.apk`.

Локально (JDK 17, Android SDK 36):

```sh
cd android
gradle :app:testDebugUnitTest :app:assembleDebug --no-daemon
```

## Постоянная подпись и установка обновлений

**Важно:** debug APK 0.1.0 подписан временным CI debug-ключом. APK 0.2.0 с другим ключом Android может отклонить как обновление (INSTALL_FAILED_UPDATE_INCOMPATIBLE). Отсутствие права обновления не связано с авторизацией.

Для перехода к стабильным обновлениям подготовь **один постоянный ключ для выпуска** и храни его у себя с резервной копией. Создать локально (не в GitHub и не на сайте):

```sh
keytool -genkeypair -v -keystore mik_tv-release.jks -alias mik_tv \
  -keyalg RSA -keysize 3072 -validity 10000
base64 -w0 mik_tv-release.jks > release.b64
```

В Settings → Secrets and variables → Actions добавь четыре *repository secrets*:

- `MIKTV_RELEASE_KEYSTORE_B64` — содержимое `release.b64`
- `MIKTV_RELEASE_STORE_PASSWORD` — пароль хранилища
- `MIKTV_RELEASE_KEY_ALIAS` — `mik_tv`
- `MIKTV_RELEASE_KEY_PASSWORD` — пароль ключа

Workflow тогда дополнительно соберёт **подписанный** `mik_tv-release-apk`. Ключи и пароли не попадают в репозиторий и не печатаются в логах. После перехода на **одну неизменную release-подпись** последующие версии ставятся поверх предыдущих при увеличении versionCode.

Так как debug 0.1.0 уже установлен, первый переход на новый release-ключ потребует удалить debug-приложение (или сохранить и повторно подписать оба APK одним и тем же ключом вне этого проекта). Перед удалением запомни настройки сервера и провайдера. **Удаление очистит локальный UUID/секрет и настройки терминала.** На backend может потребоваться деактивировать старый терминал и зарегистрировать новый, чтобы не расходовать лимит устройств абонента.

## Проверки и ограничения

- Прогон: `gradle :app:testDebugUnitTest :app:assembleDebug`.
- Новые unit-тесты `EpgGuideTest` проверяют текущее и следующее событие, ограничения архива и неверные даты.
- Реальное устройство: ранее проверен POCO M6 Pro с v0.1.0; v0.2.0 и TV-приставки требуют новой приёмки.
- Push-уведомления, PiP, UDP multicast, сложная временная EPG-шкала и публикация в Google Play пока не реализованы. Настоящая аппаратная поддержка форматов зависит от устройства.
- Для пароля нужен HTTPS. Для HTTP тестовый режим остаётся включённым, но передавать секреты через небезопасный Wi-Fi не следует.

Исходный проект в `mastergt/mik_tv/android`. Backend, PostgreSQL и Angular в этой версии не менялись.
