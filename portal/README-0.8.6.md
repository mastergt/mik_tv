# mik_tv v0.8.6 — этап A.6: главное меню и категории

Новая версия ТВ-портала с главным меню для пульта, фильтрацией по жанрам телеканалов, сохранением режима просмотра и явной командой «Продолжить просмотр». **Только файлы portal/**, без изменений NestJS, Angular, PostgreSQL и `.env`.

## Как пользоваться

- **HOME / H / Menu** — открыть главное меню. На экране также есть кнопка «☰ Меню».
- **▲ / ▼**, PageUp/PageDown — перемещаться по меню. **OK** — выбрать пункт. **BACK / Escape** — вернуться из категорий в главное меню либо закрыть меню.
- «Телеканалы» — полный загруженный список, «Категории» — жанры из API `client/streams`, «Избранное» — абонентские избранные каналы.
- В каталоге есть вкладка «Категории»; в заголовке отображается активный фильтр.
- В разделе категорий последняя строка «Загрузить ещё категории» догружает очередную страницу каналов, если она доступна.
- «Продолжить просмотр» ищет последнее выбранное устройство/провайдером ТВ через существующий постраничный API (не более 12 дополнительных страниц) и запускает его **только после явного выбора пользователя**.
- Предыдущий фильтр («Все», «Избранное» или конкретная категория) хранится в localStorage отдельно для каждого провайдера и восстанавливается, когда такая категория уже есть в первой загруженной странице. Если жанр ещё не загружен, показывается полный список, чтобы избежать пустого экрана.

## Совместимость со старыми приставками

- JavaScript **ES5**. Нет Angular, npm, новых библиотек, тяжёлых анимаций, теней для MAG и внешних шрифтов.
- Главное меню выводит максимум **11 строк DOM**; список каналов на MAG250 по-прежнему максимум 19 строк.
- Категории формируются **локально из уже загруженных** объектов `genres`, которые присутствуют в текущем API. Показанные количества не означают общее число каналов данной категории во всей базе.
- Никакого безусловного массового скачивания каталога при открытии меню и никакого автозапуска видео в Chrome.
- На реальном MAG250 могут отличаться коды кнопок HOME/MENU; при необходимости их скорректируем после испытаний.

## Применение на DEV

После review/merge Pull Request:

```bash
cd /usr/local/nodejs/dev/iptv_front
git switch main
git pull --ff-only origin main

node portal/tests/check.cjs
for test in portal/tests/*.test.cjs; do node "$test" || break; done
```

После обновления страницы Chrome должен загрузить ресурсы версии `0.8.6`. **Никакой сборки, миграций или рестарта PM2 не требуется.** Каталог на сервере можно пока не переименовывать: имя проекта и GitHub-репозитория — `mik_tv`.

## Ручная проверка в Chrome

1. Запустить портал, открыть главное меню кнопкой «☰ Меню» или `H`.
2. Стрелками выбрать «Категории»; проверить жанры и количество каналов в загруженной части.
3. Выбрать категорию и убедиться, что список ТВ отфильтрован, а вкладка «Категории» выделена.
4. Перейти к «Избранному», затем «Телеканалы».
5. После выбора канала перезагрузить страницу и выполнить «Продолжить просмотр» — канал должен открываться по явному нажатию.
6. Проверить прежние EPG, DVR, вход и экранную клавиатуру.
7. Если каталог большой, проверить «Загрузить ещё категории» и ограничение памяти.

**Проверено:** семь наборов Node.js-тестов на имитации API и MAG. Автоматический снимок Chromium не удалось завершить в среде разработки. Физическая MAG250 пока не проверялась.
