# mik_tv — Portal v0.8.3 (Stage A.3)

Лёгкая телевизионная EPG-шкала и управление DVR для браузерного портала и MAG250.

## Изменения

- Проект называется **mik_tv**: обновлены title, имя портала, идентификация версии клиента.
- Интерфейс EPG: временная шкала на 6 часов, выделенная передача, описание, отметка текущего эфира.
- Программа запрашивается за **48 часов назад / 24 часа вперёд** от текущего времени.
- В DOM выводятся максимум **13 строк EPG и 40 блоков шкалы** даже при 1000 записях.
- Архив текущей передачи запрашивается с начала, но с конечным временем не позже текущего момента.
- Запрос DVR ограничен 12 часами (ограничение существующего NestJS API); фрагмент начинается по выбранной программе.
- Управление DVR: перемотка ±60 секунд посредством повторного запроса архивного URL, пауза/продолжить, возврат LIVE.
- Запоздалые ответы DVR игнорируются после нового запроса, переключения канала или выхода.
- Добавлены тесты с имитацией DOM, API и MAG; демонстрационный HTTP-сервер выдаёт EPG.

## Управление с пульта / клавиатуры

| Контекст | Кнопки | Действие |
|---|---|---|
| LIVE | INFO / E / F2 (MAG) | Открыть EPG |
| EPG | Стрелки / PageUp/PageDown | Выбрать передачу |
| EPG | OK / Enter | Запросить архив выбранной передачи |
| EPG | Back / Escape | Закрыть EPG |
| DVR | ◄ / ► (когда панели закрыты) | Начало фрагмента −/+60 секунд |
| DVR | Play / Pause / Пробел | Продолжить / пауза |
| DVR | Back / Escape | Вернуться к LIVE (если панели закрыты) |
| DVR | R / кнопка LIVE в панели | Вернуться к LIVE |

**Ограничения:** EPG не гарантирует наличие архива. Backend вернёт DVR-источники только для настроенных источников с `dvr_url_mode='template'`. Перемотка **перезапускает** видеоплеер с новой позиции; жёлтая шкала показывает **запрошенное начало фрагмента**, а не текущую аппаратную позицию воспроизведения. Работа Pause/Resume на MAG250 зависит от прошивки и формата потока. При необходимости сначала подтвердить совместимость на реальном устройстве.

## Применение на DEV

После просмотра и слияния Pull Request:

```bash
cd /usr/local/nodejs/dev/iptv_front
git switch main
git pull --ff-only origin main

node portal/tests/check.cjs
node portal/tests/mag-adapter.test.cjs
node portal/tests/navigation.test.cjs
node portal/tests/dvr-epg.test.cjs
```

Каталог на сервере может по-прежнему называться `iptv_front`: **mik_tv** — новое имя проекта и репозитория; переносить рабочую папку необязательно.

Это статический портал: **не нужны миграции, правки .env, npm build, рестарт PM2**. Для обновления кэшированных файлов достаточно перезагрузить страницу (версия ассетов 0.8.3).

## Демонстрация без API и реальных каналов

```bash
node portal/tests/mock-server.cjs
```

Открыть `http://127.0.0.1:4411/portal/`. Демо-EРG показывает сетку вокруг текущего времени, но видео и реального DVR в mock-режиме нет.

## Проверка

Все четыре теста Node.js прошли на локальном наборе исходников; сравнение Git blob SHA гарантирует, что в PR отправлены те же байты. Полноценная визуальная проверка в Chromium блокируется ограничениями среды; физическая MAG250 пока не тестировалась.
