# mik_tv — портал v0.8.4 (этап A.4)

Обновление ориентировано на маломощные телевизионные приставки. Никаких новых библиотек, миграций или API-маршрутов backend не добавлено. Цифровой поиск при необходимости использует существующий постраничный маршрут каталога.

## Изменения

- **MAG250:** список каналов отображает не более **19 строк** и соответствующих логотипов одновременно, даже если каталог содержит сотни каналов. Выделенная строка всегда остаётся в видимом окне. Для Chrome список остаётся полностью прокручиваемым мышью, как прежде.
- **Быстрое переключение:** при закрытом меню клавиши PageUp / PageDown переключают на следующий / предыдущий канал. Также поддержаны `ChannelUp`, `ChannelDown` (при наличии соответствующих событий браузера/пульта) и коды 427/428 как дополнительные варианты.
- **Последний канал:** `Q` на клавиатуре или `ChannelPrevious`, если браузер поддерживает такое событие, возвращает к предыдущему каналу; повторное нажатие переключает между двумя.
- **Цифровой выбор:** если канала нет в загруженной части списка, портал последовательно загружает ещё страницы каталога до совпадения либо максимум **12 страниц**. Нет параллельного шторма запросов; по окончании неуспешного поиска выводится понятное сообщение.
- **Граница пагинации:** CH+ дожидается следующей страницы вместо неправильного перехода на первый канал.
- **Информационная панель:** показывается при переключении канала и скрывается через 6 секунд просмотра. Клавиша `O` в Chrome позволяет показать/скрыть панель вручную. При открытии списка панель снова видна.
- Версия терминала и ресурсов — `0.8.4`; имя проекта — **mik_tv**.

## Управление

| Кнопка | Режим | Действие |
| --- | --- | --- |
| PageUp / PageDown | Просмотр видео | Следующий / предыдущий телеканал |
| PageUp / PageDown | Открыт список | Листание списка по 7 строк |
| Стрелки ▲ ▼ | Открыт список | Выделение канала |
| OK | Открыт список | Запуск канала |
| Q / ChannelPrevious | Просмотр видео | Предыдущий просмотренный канал |
| O | Просмотр видео | Показать/скрыть информационную панель |
| 0–9 | Просмотр видео | Выбор канала по номеру, с догрузкой при необходимости |
| INFO / E / F2 | Просмотр видео | EPG |
| Back / Escape | Контекстно | Закрыть текущую панель |

**MAG250:** фактические коды CH+/CH−, прошлый канал и поведение нативного видеоплеера зависят от прошивки. На компьютере используется PageUp/PageDown; на реальной приставке сначала проверяем диагностику клавиш. Клавиша INFO в текущей раскладке по-прежнему открывает EPG, а `O` — отдельная команда информационной панели.

## Ограничения

- Проверены тесты Node.js с имитацией терминала, но **не реальная MAG250**, на которой ещё предстоит испытать прошивку, клавиши и видеоплеер.
- На MAG250 список рассчитан на управление пультом; прокрутка мышью не является целью этого режима.
- В режиме поиска по номеру ограничение 12 страниц защищает устройство/сервер; если канал за пределами лимита, открыть список и догрузить его вручную.
- Логика Stream API, подключения терминалов, пароли, DVR, EPG и Chrome HTML5-плеер не изменялись.
